# Security Policy

## Supported versions

Dartelier is under active early development. Until a stable release policy exists, security fixes are evaluated against the current default branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainers through a private GitHub channel and include only the information needed to reproduce and assess the issue.

Please include the affected commit or version, impact, reproduction steps, and a suggested mitigation if known. Avoid including real user data, credentials, or secrets.

## Scope

Dartelier is a UI foundation and should not require secrets or collect user data. Report vulnerabilities in the package, its build/release workflow, or repository automation. Third-party application code using Dartelier has its own security responsibilities.

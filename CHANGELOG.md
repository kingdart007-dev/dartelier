# Changelog

All notable changes to Dartelier will be documented here.

This project is in its early foundation stage. No stable public API has been released yet.

## Unreleased

### Added
- Centralized spacing, radius, neutral color, and typography primitives.
- Customizable light and dark themes with semantic colors, themed input decoration, and consistent 48 logical-pixel button targets.
- Reusable AppPage, SectionHeader, AppCard, AppButton, AppTextField, and EmptyState components.
- Interactive example app covering theme selection, surfaces, form input, button variants, and empty states.
- Widget tests for component behavior, validation, loading/disabled states, RTL, and enlarged text.

### Quality
- GitHub Actions checks formatting, static analysis, and tests for both the package and example app on Flutter 3.47.8.
- Added contribution guidance, security reporting guidance, and issue / pull-request templates.
